# Claude 主动打开应用

用户明确要求打开应用时，Deskhand 应能够启动应用，不要求用户手动打开。现有 native 接口只包含应用发现、状态读取和 UI 操作，没有启动工具。

- 新增 Claude MCP 启动能力，必须在用户确认的任务内，目标与任务绑定及应用范围一致。
- 支持任意已安装应用的明确注册名称或 Bundle ID，无预设应用列表；用户无需记忆 Bundle ID，由 Agent 使用确切身份。不开放 URL、文件、脚本、任意命令或启动参数。
- 启动计入动作预算，清除旧状态；取消、失败或未知结果后停止，不自动重试或换通道。
- 启动返回仅代表系统接受请求；后续仍由 Sky 读取窗口并正常申请官方权限，不承诺窗口已就绪。
- 本次不改变 pi 的工具集合，不自动发送消息，不修改配置/授权。

验收：无状态可启动，已有状态会失效；无任务/跨应用/白名单拒绝/预算耗尽不得启动；命令使用固定可执行文件和独立参数；编译、协议测试与打包验证通过。
