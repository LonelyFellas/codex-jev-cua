# 原生执行诊断与预算

## 已确认目标

1. 区分未派发、动作调用已返回、派发后结果未知；单独报告观察是否可用。不能把 Sky 的复合调用错误猜成动作失败或成功。
2. 记录初始化、工具发现、RPC 往返、官方授权等待、本地格式化和调用间隔。RPC 内部动作/截图阶段若未公开则标为不可拆分，不用估计值冒充测量。
3. 对完整可信结构的动作后返回状态签发新 stateId，减少下一次重复观察；缺失/部分/错误/跨应用状态仍需显式观察。
4. 原生与 Jev 共用不可在同一 agent turn 内通过切模式、换应用或重连重置的 180 秒/30 动作预算。到时取消在途调用并阻止后续派发；官方授权等待计入任务总时间，不受网络超时暂停影响。
5. 基准录入拒绝将超过固定预算的结果标成成功，保留失败样本。

## 边界

- 预算边界为当前 agent turn，不自动推断自然语言中的多个子任务；正式基准每槽需独立 turn/session。状态查询不启动预算。
- 预算消耗保守：向桥接提交的动作尝试计数，未知结果不退还。动作数用尽后仍允许限时内最后一次观察验证。
- 不自动重试动作、不伪造官方批准、不降低授权与索引校验、不改变 native/Jev 模式选择。
- 本次不热替换正在运行的插件，不自动执行真实桌面验收，不宣称已修复官方 Sky 内部问题。
- 默认仅将结构化元数据放入工具结果与 status；不额外落盘 UI 内容、截图、动作参数或密钥。
