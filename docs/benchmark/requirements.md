# 真实任务基准需求

目标：用固定、可重复的真实桌面任务衡量成功率、耗时、人工接管次数与错误动作，而不是演示次数。

## 边界

- 首版是人工执行协议与离线记录/汇总工具，不调用 Sky、Jev 或桌面工具，不自动授权、不联网。
- 固定任务覆盖 Calculator、TextEdit 与本地浏览器表单；只操作本次专用文档/页面，不涉及真实账户、发送、支付或删除用户文件。
- 真实运行需另行授权；Jev 需明确选择并同意第三方数据发送/费用。官方权限仍由用户决定。
- 预先生成任务 × 重复次数的运行槽；每槽只记录一次。失败后重试必须使用另一个预定槽或新的批次，不覆盖历史。
- 成功必须有最终状态验证说明和证据引用。没有证据不能记成功。
- 真实主模型执行（live）、受控实机且含模拟决策（controlled）、纯模拟（simulated）不混算。
- 不同模式、模型、提交及环境使用独立批次。未完成槽明确展示，不宣称完整基准已通过。

## 验收

1. 一个命令生成固定任务集与全部运行槽；一个命令校验并汇总结果。
2. 汇总显示计划数、已记录数、未完成数、各状态、严格无人工接管成功率、最终成功率、耗时中位数/P95、人工接管及错误动作数。
3. 阻塞、取消、失败不从已记录分母删除；耗时包含等待/授权，不以成功样本耗时冒充全体耗时。
4. 非法计数、无证据成功、缺槽、重复槽、篡改任务集均拒绝汇总；用离线单元测试验证。
5. 工具不写入桌面数据，不自动采集界面、密钥或截图；证据由操作者审阅并留在包目录外。
